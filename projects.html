💬Chatbot (OpenAI API)

OpenAI 相容 API 的網頁對話程式：填入 API 網址與金鑰即可與大語言模型聊天，設定與對話歷史存在瀏覽器 localStorage。含多版本（Qwen2.5、GPT-4.1、Gemini 整合版），支援圖片辨識、Markdown、Mermaid 與 MathJax 數學公式。
